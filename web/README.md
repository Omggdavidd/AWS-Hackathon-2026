# web

Next.js 16 product UI (ADR-0010): dashboard, loop detail, approvals, activity feed. Server components and server actions read the ledger through `@openloop/shared`; the browser never sees AWS or Google credentials.

```
pnpm --filter @openloop/web dev     # http://localhost:3000
pnpm --filter @openloop/web build
```

Data source today: `LocalLedgerStore` on `.openloop/ledger.json` at the repo root, created from `demo/seed-ledger.json` on first run (`OPENLOOP_LEDGER_FILE` overrides the path, `OPENLOOP_RESET=1` re-seeds). Delete the file to reset the demo. The DynamoDB adapter and the agent invocation arrive with plan steps 9 and later.

`AGENTS.md` in this directory is generated by `next dev` and points agents at the bundled Next.js docs; keep it committed.
