# MVP: Open Loops end to end by Sunday

Status: active
Related: `docs/hackathon/SPEC.md` §13, §14, §16; ADRs 0003 to 0012

## Objective

By Sunday Sep 13 midday, a judge can clone the repo, run the seeded demo, watch a forgotten deposit surface with evidence, see a later receipt auto-resolve another loop, approve one high-risk action, and see the agent deployed on AgentCore Runtime. Video recorded Sunday, submitted Monday by 7:00 PM ET.

## Scope

In: everything under "Must ship" in `SPEC.md` §13.
Out: everything under "Stretch" in §13 until must-ship is done end to end. Live Gmail is the first stretch item.

## Affected systems

`web/`, `agent/`, `packages/shared/`, `demo/`, one DynamoDB table, Vercel project, AWS account.

## Approach

Each step is one PR unless noted. Steps within a day are independent where marked (∥) so several people and agents can work at once.

**Thu Sep 10 (Phase 1 to 2)**
1. Accept ADRs 0003 to 0012 (team decision, PR on `STATUS.md` and ADR statuses).
2. Account chores, no PR: AWS credit request, Devpost registration, Bedrock Anthropic use-case form, `agentcore` CLI first deploy of the hello-world template to bootstrap CDK, Google Cloud project with APIs enabled and OAuth client in Testing.
3. Workspace scaffold: pnpm workspace, `.nvmrc`, Biome, Vitest, `packages/shared` with the four record schemas and `LedgerStore` interface plus `LocalLedgerStore`, `demo/` fixtures for the §14 scenario, LICENSE. Fill `AGENTS.md` *Commands*.
4. ∥ `agent/` from the CLI template, trimmed, depending on `packages/shared`; graph skeleton with the five roles and stub tools; `agentcore dev` runs.
5. ∥ `web/` from `create-next-app --biome`, dashboard shell with four state sections reading `LocalLedgerStore` seeded from `demo/`.

**Fri Sep 11 (Phase 3)**
6. Extractor with structured output over fixture messages; loops appear from seed data end to end through the local adapter.
7. ∥ Investigator: resolution detection across later fixture messages (receipt closes a loop); `transition_loop` with reasons; timeline.
8. ∥ Loop detail view: why it exists, what was found, confidence, consequence, evidence links, "I already did this".
9. `DynamoLedgerStore`, table script, shared adapter test suite passing on both adapters; deploy agent with `agentcore deploy`; web invokes the runtime.

**Sat Sep 12 (Phase 3 to 4)**
10. Risk Judge and `ProposedAction` lifecycle; approval queue in the UI; execution refuses non-approved high-risk actions (test).
11. ∥ Action Agent with one real safe action: draft email and create calendar event on fixtures; activity feed.
12. ∥ "Catch me up" and "Handle what you can".
13. Failure paths: duplicate message, already-resolved loop, ambiguous deadline, unsafe action.

**Sun Sep 13 (Phase 4 to 5)**
14. Feature freeze at midday. Polish, mobile layout, first-scan animation.
15. README setup and testing instructions verified on a clean machine; architecture diagram into `docs/architecture/`; `docs/hackathon/DEMO.md`.
16. Deploy web to Vercel production; record and time the video.

**Mon Sep 14 (Phase 5)**
17. Clean-machine test, secrets audit, video upload, Devpost form, submit by 7:00 PM ET.

## Dependencies

Step 3 before 4 and 5. Step 9 needs the AWS account bootstrapped (step 2). Live Gmail (stretch) needs the Google project in Testing with team members as test users.

## Risks

| Risk | Mitigation |
|---|---|
| `workspace:*` dependency does not bundle in `agentcore deploy` (ADR-0012) | Try on day one with the template; fallback is a build step that copies shared code into `agent/` |
| Bedrock Anthropic use-case form delays first model call | Submit today; Nova 2 Lite as a temporary model if blocked |
| Strands TypeScript Graph semantics differ from Python (AND-join edges) | Design the graph as a linear pipeline with one fan-out; no OR-joins |
| Google restricted scopes and 7-day token expiry | Seeded path is primary (ADR-0006); live path is stretch |
| Team spends the demo on LLM talk (§17 traps) | Demo script follows §14 timing table exactly |
| Four days, several people, one `main` | PR-sized steps, rebase daily, Context Sync per PR, feature freeze Sunday noon |
